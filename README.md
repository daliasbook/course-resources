# course-resources

Resources for the online courses of Cartea Daliei (Dalia's Book Association).

## Contents

### T10: Agile for Teens with Python

Sample projects for the team project of Module 1. Each project is a console app split into one file per team member, plus a `main.py` that shows the menu and calls everyone's code.

| Project | Level | Sample code | Template board |
|---|---|---|---|
| Team Quiz | Easy | [team-quiz](t10-agile-for-teens/team-quiz) | [T10 - Quiz-ul echipei](https://github.com/orgs/daliasbook/projects/4) |
| Text Adventure | Easy | [text-adventure](t10-agile-for-teens/text-adventure) | [T10 - Aventura text](https://github.com/orgs/daliasbook/projects/5) |
| Mini Games Arcade | Medium | [mini-games-arcade](t10-agile-for-teens/mini-games-arcade) | [T10 - Sala de jocuri mici](https://github.com/orgs/daliasbook/projects/6) |
| Student Assistant | Advanced | [student-assistant](t10-agile-for-teens/student-assistant) | [T10 - Asistentul elevului](https://github.com/orgs/daliasbook/projects/7) |

## For mentors

- **Template boards:** open the board, then **... → Make a copy**. Choose your personal account as owner and check **Draft issues will be copied**.
- **Sample code:** shows what the finished app can look like. Students build their own version, one task at a time.

To run a sample, open its folder in a terminal and run `python main.py` (`python3 main.py` on Mac).
