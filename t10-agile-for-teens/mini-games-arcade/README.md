# Mini Games Arcade

Sample solution. Each game is in its own file, written by a different team member. `main.py` shows the menu and calls them.

## Files

- `main.py`: title, team, menu
- `count_vowels.py`
- `guess_number.py`
- `hidden_word.py`
- `odd_even.py`
- `riddle.py`
- `times_table.py`

## How to run

```
python main.py
```
