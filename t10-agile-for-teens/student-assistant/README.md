# Student Assistant

Sample solution. Each module is in its own file, written by a different team member. `main.py` shows the menu and calls them.

## Files

- `main.py`: title, team, menu
- `converter.py`
- `grades.py`
- `homework.py`
- `password_checker.py`
- `text_stats.py`
- `timetable.py`

## How to run

```
python main.py
```
