# Team Quiz

Sample solution. Each category is in its own file, written by a different team member. `main.py` shows the menu and calls them.

## Files

- `main.py`: title, team, menu
- `animals.py`
- `geography.py`
- `music.py`
- `science.py`
- `sports.py`
- `video_games.py`

## How to run

```
python main.py
```
