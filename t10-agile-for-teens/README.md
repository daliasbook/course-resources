# T10: Agile for Teens with Python - sample projects

Sample solutions for the four team projects of the course. Each project is a console app split into one file per team member, plus a `main.py` that shows the menu and calls everyone's code.

| Folder | Project | Level | Board |
|---|---|---|---|
| [team-quiz](team-quiz) | Team Quiz | Easy | [T10 - Quiz-ul echipei](https://github.com/orgs/daliasbook/projects/4) |
| [text-adventure](text-adventure) | Text Adventure | Easy | [T10 - Aventura text](https://github.com/orgs/daliasbook/projects/5) |
| [mini-games-arcade](mini-games-arcade) | Mini Games Arcade | Medium | [T10 - Sala de jocuri mici](https://github.com/orgs/daliasbook/projects/6) |
| [student-assistant](student-assistant) | Student Assistant | Advanced | [T10 - Asistentul elevului](https://github.com/orgs/daliasbook/projects/7) |

## How to run

Open a project folder in a terminal and run:

```
python main.py
```

On Mac, use `python3 main.py`.

These samples are for mentors. Students build their own version, one task at a time.
