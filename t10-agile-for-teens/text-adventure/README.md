# Text Adventure

Sample solution. Each place is in its own file, written by a different team member. `main.py` shows the menu and calls them.

## Files

- `main.py`: title, team, menu
- `castle.py`
- `cave.py`
- `forest.py`
- `mountain.py`
- `river.py`
- `village.py`

## How to run

```
python main.py
```
